# Implementation notes

## Diagnosis

The site's underlying art direction did not fail. The homepage hierarchy did.

The opening experience had accumulated ten navigation choices, eight hero actions, visitor-routing cards, conversion widgets, repeated lore summaries, release features, merchandising, mailing-list capture, and professional-resource links. The result was technically complete but artistically noncommittal: every destination had equal authority, so nothing had authority.

## Correction

The new homepage is not another redesign. It retains the current visual vocabulary and page ecosystem while restoring a deliberate sequence:

**enter → hear Salt → encounter evidence → meet the Nine → enter the Orchard → choose a secondary door**

Press, licensing, shop, artifacts, updates, and social destinations remain available. They no longer interrupt the first encounter with the music and world.

## Scope

Only `index.html` is replaced. No lore page, Sister page, release page, press asset, build script, dependency, or hosting configuration is changed.
